# Changelog

This is the changelog for the `lch-skills` repository as a whole. Each skill also keeps its own changelog under `skills/<name>/CHANGELOG.md`.

## [0.1.0] - 2026-06-23

First public release.

- Added `ground-or-abstain` v2.2.1, a verification discipline for AI assistants, with full methodology, three rounds of adversarial test results, citation metadata, and Apache-2.0 license.
- Established the monorepo structure: each skill is a self-contained folder under `skills/`.
- Documented the system thesis (prose raises the floor, a runtime harness is the ceiling) and a roadmap of the remaining skills, including which are kept private as personal IP.

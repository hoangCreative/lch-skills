# skill-upgrade

A repeatable process for taking an existing behavioral skill from "works" to publish-grade, and past it. Distilled from a real upgrade (what-for-and-how v2 to v3.1).

Seven steps: spec the gap and lock the architecture, stress-test at scale with an adversarial council and an explicit cut/keep/fix/add boundary, rewrite and anchor in real prior-art (community first, never memory), separate the universal engine from context-bound parts, formalize the test apparatus, build contribution infrastructure that holds the bar without a gatekeeper, then audit and version. Going past 100% is one more move: make the skill name its own ceiling and spec the harness past it.

Two governing rules: an upgrade needs a what-for (name the gap or there is no upgrade), and the process must obey the discipline of the skill it upgrades (eat its own dogfood).

## Install
Copy this folder into `~/.claude/skills/`. The `name` field (`skill-upgrade`) becomes the trigger.

## Origin
The sequence is the one that took `what-for-and-how` from a 50-case interim package to an open-methodology release, generalized so it runs on any skill. Author: Le Cong Hoang (LCH).
